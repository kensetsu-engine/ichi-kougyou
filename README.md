# 株式会社一工業 デモサイト（提案用カンプ）

千葉県東金市・株式会社一工業のサイトリニューアル提案用デモです。

## 開き方
- GitHub Pages：リポジトリの Settings → Pages で `main` ブランチ / `/(root)` を公開すると、`index.html` からトップページに移動します。
- ローカル：簡易サーバーで開いてください（例：`npx serve .`）。ファイルを直接ダブルクリックすると一部が読み込まれません。

## 構成
- `*.dc.html` … 各ページ（トップ＋下層14ページ）
- `SiteHeader.dc.html` / `SiteFooter.dc.html` … 共通ヘッダー・フッター
- `support.js` … ページ描画ランタイム
- `nav-router.js` … デモ内のページ遷移（本番スラッグ → ファイル名）
- `site-motion.js` … スムーススクロール・写真パララックス・マーキー等の共通モーション
- `add.css` … 本番CMS（Cuezilla）動的パーツ用の貼り付けCSS
- `images/` … 画像
